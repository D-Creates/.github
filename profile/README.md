### What we do

| | |
|---|---|
| 📱 **Apps for iPhone, iPad and Mac** | Native Swift apps, from idea to the App Store. |
| 🛠️ **Prototyping and FabLab** | 3D printing, electronics, the app that drives the part. |
| 🤖 **AI automation** | Assistants and workflows for local businesses, supervised by a human. |
| 🌐 **Websites** | Fast, accessible sites with no trackers. |
| 📷 **Photo and video** | Portraits, events, brand videos. |

### Our direction

Turning good open-source projects into apps for everyone, on one Rust core that runs on every platform, always crediting the original authors.
